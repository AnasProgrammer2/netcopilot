## NetCopilot 0.17.2

Interface polish on top of 0.17.1.

- Help now explains the three ARIA modes — Investigate, Change and Autopilot — and how Production, Staging and Lab limit what each can do.
- Tools menu uses quiet, uniform icons in line with the rest of the interface.
- Jump host hint in the connection dialog reads as a plain note instead of a warning.
