## NetCopilot 0.17.1

Security fixes on top of 0.17.0 (change control, Termius import, new interface).

### Security
- Testing a custom AI endpoint (Ollama / LM Studio) with a new, unsaved URL no longer sends the saved API key to that URL — only a key typed in the form is used.
- The shipped app ignores a development renderer URL inherited from the environment, so no outside page can be loaded with NetCopilot's privileges.
