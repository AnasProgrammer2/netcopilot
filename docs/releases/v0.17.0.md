## NetCopilot 0.17.0

### ARIA change control — safe changes on production gear
ARIA no longer types configuration into your devices. Its own commands are read-only in every mode; every change goes through a **change plan** that NetCopilot applies itself.

- **Three modes:** Investigate (read-only), Change (ARIA proposes, you approve), Autopilot (lab and staging devices only).
- **Environment per connection:** Production, Staging or Lab. Production never runs Autopilot.
- **Platform safety nets:** Junos `commit confirmed`, Arista EOS config session with `commit timer`, Cisco IOS `reload in` when the management path is touched, NX-OS checkpoint, RouterOS Safe Mode.
- **Every plan runs the same way:** config snapshot → pre-checks → safety net → apply (automatic back-out on the first rejected line) → verify → **Keep** or **Roll back**, with a countdown on timer-based platforms.
- **Change policy:** keep production read-only, or require a written reason for changes outside a maintenance window.
- **Change History:** every plan with its diff and execution log, exportable as Markdown for change tickets; the pre-change config is kept encrypted inside NetCopilot.
- Device output reaches the model marked as untrusted data, so text on a device can't instruct ARIA.

### Import from Termius
- Import hosts from a Termius (or any) CSV export — groups, tags, ports and usernames come across, and passwords in the file can go straight into the encrypted vault (optional).

### A calmer, native interface
- Unified title bar with tabs, native macOS menu, system font, follows the OS light/dark theme.
- New visual system: colour only where you need to act, five type sizes, every text level WCAG AA in both themes, no gradients or glows.
- Quieter ARIA panel: no avatars, one-row header, commands as compact rows, approvals highlighted only when needed.

### Fixes
- Proxy settings in the connection dialog are now saved.
- Inline code in ARIA answers no longer renders as a full code block.
- Closed several ARIA guardrail bypasses (control characters, cross-session targets, Auto Watch turns).
- Sidebar "Reset all" restores the real default sort.

> Change plans are applied with each vendor's own rollback mechanism. As with any automation, try them on a lab device before relying on them in production.
